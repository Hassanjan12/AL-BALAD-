# Grill Al Balad – Website (Demo)

موقع مطعم **Grill Al Balad** (مشاوي على الفحم). نسخة عرض لأخذ موافقة صاحب المحل.

- لغة أساسية ألماني، مع زر للتبديل للعربي.
- منيو تفاعلي مع سلة، والطلب بينبعت كرسالة جاهزة على واتساب.
- بدون أي build: افتح `index.html` بالمتصفح مباشرة.

## وين بتتعدّل الأشياء

كل المحتوى موجود بملف واحد: `assets/js/data.js`

| الشي | المكان |
| --- | --- |
| رقم واتساب المحل | `config.whatsapp` (مثلاً `4930123456789`، بدون + أو مسافات) |
| الهاتف والعنوان والسوشيال | `config` |
| الأطباق والأسعار (بالسنت: `1650` = 16,50 €) | `menu` |
| كل نصوص الموقع بالألماني والعربي | `i18n.de` و `i18n.ar` |
| أوقات الدوام | `visit.time1` بـ `i18n` |

## قبل النشر

- [ ] رقم واتساب حقيقي بـ `config.whatsapp` (هلق فاضي، فواتساب بيفتح وبيخليك تختار المحادثة).
- [ ] العنوان، الهاتف، أوقات الدوام، روابط السوشيال.
- [ ] صور حقيقية للمطعم بدل صور Unsplash المؤقتة (`assets/img/`، شوف `CREDITS.md`).
- [ ] مراجعة الأسعار والأطباق مع المحل (مقروءة من صور المنيو).
- [ ] **Impressum** و **Datenschutzerklärung** (إلزاميين بألمانيا).
- [ ] خريطة Google Maps بقسم "Kontakt".

## الملفات

```
index.html            هيكل الصفحة
assets/css/style.css  التصميم
assets/js/data.js     المحتوى (منيو، أسعار، نصوص، تواصل)
assets/js/app.js      المنيو التفاعلي، السلة، واتساب، تبديل اللغة
assets/img/           الصور (مؤقتة)
```
